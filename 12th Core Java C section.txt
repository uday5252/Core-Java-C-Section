when multiple threads are accessing same run(), then we will get inconsistent output ==> Race Condition

Solution for Race Condition ==> SYNCHRONIZATION

SYNCHORNIZATION is a mechanism / process where java allows only one thread to access the run() instead of allowing multiple threads at a time!

We can achive synchronization in 2 ways:-
1) using synchronized block 
2)using synchronized method

Inter Thread Communication

One thread will try to communicate with another thread in order to complete the task.

This can be done using 3 methods:-
1) wait() 
2)notify()
3) notifyAll()
